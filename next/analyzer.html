What Antares analyzes

Every platform's hard parts — accounted for.

Each BI platform has its own quirks. The Analyzer knows them — and scores every workbook on exactly how hard each one is to move.

Hardest to migrateHard

  • LOD expressions (FIXED / INCLUDE / EXCLUDE)

    Implicit granularity must be re-expressed downstream — every occurrence is counted and scored.

  • Data blending

    Blends aren't joins; flagged wherever the target needs an explicit data model.

Needs attentionModerate

  • Table calculations

    Partition and addressing semantics differ from window functions.

  • Custom SQL

    Dialect-specific SQL is detected and rated for portability.

  • Dashboard actions & filters

    Conditional and interaction logic is inventoried per dashboard.

  • Row-level security

    User-filter logic is surfaced for role mapping on the target.

StraightforwardEasy

  • Calculated fields & measures

    Standard aggregations map cleanly.

  • Parameters

    Catalogued with every downstream reference.

  • Sets, groups, bins & hierarchies

    Structural objects enumerated and carried over.

FAQ

Common questions.

How long does analysis take?

Most environments complete in minutes. Large estates (1000+ workbooks) may take up to 30 minutes.

What access does Antares need?

Read-only access to Tableau Server or Tableau Cloud. No write permissions are ever requested.

Is my data secure?

Antares analyzes workbook metadata — structure, calculations, and usage stats. It never reads your underlying business data.

Can I analyze a subset of workbooks?

Yes. You can filter by project, site, or select individual workbooks for a targeted analysis.

What's in the readiness report?

A Migration Readiness Score per workbook, complexity breakdown by feature type, auto-convertible percentage, effort estimate, and prioritized conversion order.
